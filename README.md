# CaseTracker-AI

A starter repository for the CaseTracker AI desktop app and agent pipeline.

## Planned structure

- `agents/` — autonomous processing agents
- `data/` — local datasets and generated outputs
- `desktop/` — native app project
- `docs/` — design and architecture notes

## First milestone

Build the foundation for:

- PDF import and parsing
- Episode extraction into structured JSON
- SwiftUI + SwiftData desktop browser
- Local storage for the 58-case master episode set

## Suggested stack

- SwiftUI
- SwiftData
- Python bridge for PDF parsing and content extraction
- OpenAI API for research and narration workflows
- FFmpeg for media production
